# Paradise Nursery Shopping Application

Paradise Nursery is an online plant store application built with React and Redux Toolkit. Users can explore aromatic and medicinal house plants, add them to a shopping cart, adjust quantities, and see dynamic pricing updates in real-time.

## Features
- Landing page with company mission and Get Started button.
- Categorized plant listings.
- Redux Toolkit shopping cart management.
- Dynamic cart counter and cost calculation.
